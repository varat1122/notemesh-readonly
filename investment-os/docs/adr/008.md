# ADR 008: Provider independence and rights

Date: 2026-10-22

Status: **Accepted — adapter design; vendor selection Proposed**

## Context

AI, Drive, market data and hosting availability, cost and licensing change over time.

## Decision

Provider adapters exchange internal UUID-based typed DTOs; provider keys/tickers/URLs remain provenance or locator metadata. Preserve source bytes, data versions, rights and exportable manifests. No SDK is imported in domain.

## Alternatives

One vendor-native schema reduces initial code but makes replacement and evidence replay harder. A universal connector platform adds complexity before known needs.

## Consequences and limits

Adapters still need provider-specific coverage, quotas, corporate actions, auth and license tests. Unknown rights never imply model-input or redistribution permission.

## Approval and migration

Select actual model/market providers only after coverage/cost/terms review. Paid subscriptions, model egress, X API and real Drive grants require separate owner approval.
