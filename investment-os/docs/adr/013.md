# ADR 013: Reproducible excerpts and original-source citation readback

Date: 2026-10-23

Status: **Accepted — synthetic local development. Real source grants, security release and protected evidence approval remain outside this scope.**

## Decision

Add deterministic extraction from registered, unverified synthetic local originals. Reuse the existing static-file admission policy and parser dependencies; no new provider or package is introduced. Extraction revalidates original bytes and format inside the same credential-free, resource-limited worker boundary as intake. Registry and original files are never changed by extraction.

The output is a versioned derived artifact under the marked local store's immutable journal, not a new source of truth or a verified Evidence Register entry. Document ID/revision, canonical metadata hash, original byte SHA-256 and parser profile bind the result. The profile includes algorithm `synthetic-excerpts-v1`, admission policy, exact Python version and pypdf/openpyxl/defusedxml versions. Excerpt UUIDs and full-output digests are deterministic; creation time/actor are kept in the checksum-protected checkpoint envelope outside the deterministic artifact. Semantic parser changes must bump the algorithm version. Older output may be retained, but fresh citation certification requires its matching parser environment.

## Locator and value rules

- PDF: one-based page plus zero-based, end-exclusive Unicode character offsets in the pinned parser's extracted page text. Chunks contain at most 4,000 characters. These are neither PDF byte offsets nor visual bounding boxes. No table layout, reading-order or OCR claim is made. Pages with no extractable text are explicitly listed; an entirely empty extraction has `no_text`, not a fabricated summary. Mixed image/text pages can still contain unextracted material.
- CSV: one-based logical record and column, including the header record; physical line start/end are also retained for quoted multiline cells. UTF-8 BOM is removed as encoding metadata, CSV quoting is decoded, and field strings/newlines/numeric lexemes are otherwise preserved. No date/unit/numeric inference.
- XLSX: workbook sheet name and exact cell coordinate with style index. Read bounded OOXML directly after admission, preserving numeric `<v>` strings instead of converting through float. Inline/shared rich strings are decoded; phonetic hints are not substituted for the original string. Booleans retain the stored `0`/`1` lexeme with type metadata. Date serials remain raw numeric values and explicit date cells remain lexical strings. Styles, locale formats, merged-cell display and calendar conversion are not interpreted. Ambiguous/duplicate cells and inconsistent row coordinates fail closed. Blank cells are omitted.

Every excerpt includes its text digest and immutable `untrusted_data=true` / `independent_evidence=false` markers. Source text cannot change authority or invoke any tool. These markers accompany the actual absence of a model/runtime executor; they are not themselves an injection defense for a future LLM.

## Persistence, limits and proof

Existing dummy researcher/owner principals can create derived artifacts; a dummy reader can verify a supplied artifact without writing. The registry's synthetic license/classification restrictions still apply. Source reads require a local `objects/<sha256>` key, exact byte size and digest. Cached artifacts are read only after checking the current original again. Cache keys bind document metadata and parser profile. Immutable checkpoints and per-key locks make concurrent/repeated extraction produce one artifact; failed writes can retry without modifying the source or database.

Limits: existing input/admission limits; 2,000 nonempty excerpts, 120,000 total characters, 10,000 per value, and 750,000 serialized artifact bytes. Resource exhaustion or a limit violation fails the whole extraction; it never returns a silently truncated success. Capture can succeed while extraction fails, preserving the original for later reconciliation.

`verify_excerpt` does not trust a cached text hash alone: it reloads the registered revision, reopens and hashes original bytes, reparses them and compares the entire deterministic output before returning the requested excerpt. Even a self-consistent forged text/hash/UUID/output digest fails this check. This proves reproducible source attribution, **not** source truth, financial correctness, complete visual coverage or independent evidence.

## Remaining work

Semantic source/event dedup and corrections, unit/currency/calendar normalization, table interpretation, OCR, human claim/evidence review, real authorization/revocation, quotas/antivirus and coordinated object/database backups remain open. The database-only backup drill does not back up these local derived files. Derived artifacts can be rebuilt only while both originals and compatible parser versions remain available. No ledger, paid AI, real Vault, production deployment or automated trading is involved.
