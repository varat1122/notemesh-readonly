# ADR 006: Separate quant computation from AI reasoning

Date: 2026-10-22

Status: **Accepted — contract boundary**

## Context

Narrative plausibility is not computed evidence; stochastic output cannot substitute for a reproducible backtest.

## Decision

LLM proposes hypotheses and tool requests; deterministic Python/SQL engine owns computation. QuantRun binds data/code/environment/model/parameters/as-of/cost/bias assumptions. Missing results stay not_computed.

## Alternatives

All-in-LLM calculations are easy to demo but not auditable. A separate quant microservice is unnecessary for P0.

## Consequences and limits

Engine implementations and point-in-time data quality come in P4. Reproduction criteria and numerical tolerance must be specified per algorithm.

## Approval and migration

Provider swaps do not change quant IDs or artifacts. No inference vendor or paid evaluation is authorized by this ADR.

Evidence: Master Blueprint §§01–05, 16–18, 21–23; actual validation is recorded separately in IMPLEMENTATION_STATUS.md.
