# ADR 009: Safe cloud migration and operational approval

Date: 2026-10-22

Status: **Requires Owner Approval — not enabled**

## Context

Cloud exposure changes cost, identity, data custody, network and recovery assumptions.

## Decision

Propose provider-independent Docker deployment with real OIDC/OAuth, TLS, private PostgreSQL, encrypted object/backup storage, local-agent enrollment, distinct roles, quotas and tested restore. Preserve UUIDs and storage ownership.

## Alternatives

Remain local until gates pass; managed hosting reduces operations but introduces cost and custody obligations. Cloud vendor selection is deliberately open.

## Consequences and limits

No production deployment, domain change, live credentials, real Vault sync, paid model or risk-limit policy is approved here. Dummy P0 auth must be removed before exposure.

## Approval and migration

Owner must approve provider/budget, data rights/export, key custody, retention/RPO/RTO, auth/agent scope and rollback plan. Validate restored snapshot and hashes before activating a new writer; keep previous writer stopped.
