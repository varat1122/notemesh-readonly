# ADR 005: Local-first authorized Vault

Date: 2026-10-22

Status: **Accepted — P0 synthetic; real access Requires Owner Approval**

## Context

A cloud process cannot read a desktop folder by prompt alone, and Sync is not write authority or backup.

## Decision

MVP places backend and authorized local agent beside the Vault. P0 allows only a marked synthetic fixture directory and read-only operations. One authoritative writer and scoped CAS/journal protocol are designed for P2.

## Alternatives

Cloud-first requires enrollment/replica/transport decisions before useful evidence work. Raw network fileshares broaden exposure.

## Consequences and limits

P0 is Linux/POSIX-tested because secure dir_fd/O_NOFOLLOW behavior is used. Windows agent implementation needs platform-specific verification before support is claimed.

## Approval and migration

Move API/worker independently; enroll local agent over authenticated outbound transport or use explicit replica. Never automatically mount a production directory.
