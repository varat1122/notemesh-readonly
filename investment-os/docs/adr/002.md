# ADR 002: Obsidian plus structured database

Date: 2026-10-22

Status: **Accepted — P0 design baseline**

## Context

Human-readable investment interpretation and transactional identity/audit have different needs.

## Decision

Markdown owns narrative; PostgreSQL owns identity, status, semantic edges, approvals and transactional records. Note registry stores path/hash/version and derived index metadata, not a competing narrative truth.

## Alternatives

All-Markdown weakens atomic relational constraints; all-DB loses local human-readable notes. A proprietary knowledge SaaS would tie canonical identity to a vendor.

## Consequences and limits

Cross-store updates need journaling and reconciliation. Wikilinks are navigation, not proof of economic relationships. P0 reads only synthetic Markdown; writeback is P2.

## Approval and migration

Move note paths without changing note UUIDs; rebuild indexes from authoritative Markdown and preserve operation journals. Real Vault enrollment requires owner approval.
